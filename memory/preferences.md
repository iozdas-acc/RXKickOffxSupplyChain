# Preferences

Durable taste rules — patterns the client keeps choosing.
Write here when a preference is confirmed twice or explicitly stated.
Preferences are applied silently — no need to re-explain them each session.

**ID format:** `P-[CATEGORY]-[NNN]`

| Prefix | Category |
|--------|----------|
| `TYPO` | Typography |
| `COLOR` | Color |
| `SPACE` | Spacing & Layout |
| `TONE` | Tone & Copy |
| `MOT` | Motion & Animation |
| `TECH` | Technical |

Use these IDs to cross-reference from `pages/<name>/design.md` (override table) and `pages/<name>/build.md`.

---

## Format

```
## P-[CATEGORY]-[NNN] — [Preference name]
- Rule: [what to always/never do]
- Origin: [where the client first chose this — e.g., "approved hero mockup v2"]
- Scope: global | page: <name>
- Added: YYYY-MM-DD
```

## Typography `TYPO`

### P-TYPO-001 — No AI-default fonts
- Rule: Never use Inter, Roboto, Space Grotesk, or system-ui. Choose something characterful and specific to the brand.
- Origin: Client direction — site must not look AI-generated
- Scope: global
- Added: 2026-03-25

---

## Color `COLOR`

### P-COLOR-001 — Brand color palette
- Rule: Purple → orange gradient as primary. Supporting: teal/blue (Kidovation alien), warm orange (Future Labs rocket). No flat corporate palettes.
- Origin: New logos (logos-new.png) — all three brands share the purple/orange gradient family
- Scope: global
- Added: 2026-03-25

### P-COLOR-002 — Brand family consistency
- Rule: All three brands (Innovation X, Kidovation, Future Labs) share the same gradient language but each has a distinct character color — teal for Kidovation, orange/flame for Future Labs, purple/orbit for Innovation X.
- Origin: New logo set — designed as a brand family
- Scope: global
- Added: 2026-03-25

---

## Spacing & Layout `SPACE`

### P-SPACE-001 — Real photography over illustration
- Rule: Always use real event photos and real headshots. Never use stock photos, AI-generated imagery, or generic illustration.
- Origin: Client has real event photos (23) and team headshots (7 across 3 generations)
- Scope: global
- Added: 2026-03-25

### P-SPACE-002 — Generational team structure
- Rule: Team section must reflect generational hierarchy — Gen 1 (Founder), Gen 2 (Leads), Gen 3 (Current). Not a flat grid.
- Origin: Client direction — "team in generations would be good"
- Scope: page: team / about
- Added: 2026-03-25

## Technical `TECH`

### P-TECH-001 — No AI-generated icons or illustrations
- Rule: Never use generic icon libraries (Heroicons, Lucide, Font Awesome used generically) or AI-generated decorative elements. Icons must feel intentional and brand-specific.
- Origin: Client explicit — "I don't like it when it looks like it is generated by AI"
- Scope: global
- Added: 2026-03-25

### P-TECH-002 — Not fluffy
- Rule: Design should feel real, grounded, and direct. No excessive rounded corners, pastel gradients, glassmorphism, or soft AI-slab patterns.
- Origin: Client — "nothing too fluffy"
- Scope: global
- Added: 2026-03-25
