# RX Lexicon — preferred vs banned

Words shape voice. Use the left column. Never use the right column.

---

## Verbs — use these

| Verb | Why it belongs |
|---|---|
| pioneer | Claims the frontier; active, not reactive |
| provoke | Makes inaction visible; forces choice |
| codify | Turns wins into reusable assets |
| challenge | Consensus is a starting point, not an endpoint |
| reject | Draws a line; no fence-sitting |
| champion | Backs the unfashionable right thing |
| surface | Makes the unseen visible |
| inhabit | Owns the space fully |
| sit with | Stays in the hard problem |
| demand | Raises the bar; doesn't ask nicely |
| compound | Wins build on each other |
| ship | Moves from talk to reality |
| prove | Evidence over opinion |
| own | Accountable, not involved |
| move first | Acts before the path is clear |
| discover · build · deploy | The loop; never separated |

## Verbs — never use these

| Banned | Why | Replace with |
|---|---|---|
| leverage | Empty. What does it mean? | use · wield · compound |
| empower | Consultant word; nobody says it at work | equip · back · trust |
| unlock | Suggests the thing was hidden, not hard | build · prove · ship |
| enable | Vague. Enable what? | make X possible · let X happen |
| streamline | Process-theatre word | cut · simplify · remove |
| utilize | Pretending "use" isn't enough | use |
| optimise (as cliché) | Fine in *"optimise for outcomes, not outputs."* Banned when it means nothing. | improve · focus on |
| drive (as verb) | "Drive transformation" says nothing | ship · deliver · prove |
| align | Corporate meeting word | agree · decide · choose |
| operationalise | Committee word | make it real · ship it · run it |
| synergise / synergy | Never, ever | work together · compound |

## Adjectives — use these

| Adjective | Why it earns its place |
|---|---|
| small | Small squads, small prototypes, small wins — a structural choice |
| cross-functional | Specific team shape, not vibes |
| embedded | Where the work actually happens |
| bold | If there's evidence behind it |
| concrete | Opposite of abstract |
| unproven | Reclaimed — an invitation |
| uncomfortable | Truths and choices, not vibes |
| structured (as in *structured disagreement*) | Conflict with form |
| reusable | Codification in one word |

## Adjectives — never use these

| Banned | Why |
|---|---|
| robust | Means nothing. Engineers hate it. |
| comprehensive | "We did everything" without proof |
| seamless | It isn't |
| holistic | Agency word |
| cutting-edge | Already outdated |
| world-class | Self-congratulatory |
| best-in-class | Same |
| innovative | Show it, don't claim it |
| transformative | The noun "transformation" is fine; this adjective is puffery |
| game-changing | Clichéd beyond repair |
| next-generation | Everything is next-generation |
| turnkey | Never |
| bespoke (as puffery) | Fine in a tailor; dead in tech |

## Nouns — preferred framings

| Prefer | Over | Why |
|---|---|---|
| outcome | output / deliverable | The manifesto picks this fight explicitly |
| mission | project / workstream | Stakes, not tasks |
| step change | improvement / uplift | Magnitude matters |
| the win | the result | Ownership shows |
| the pain | the problem (when embedding) | Specific, felt |
| squad | team (when cross-functional) | Small, tactical |
| prototype | MVP / POC | Ships; doesn't defer |
| playbook · agent · asset | framework / methodology | Reusable, portable |
| conviction · velocity · integrity | the trifecta (manifesto header) | Use as a set |

## Nouns — avoid

| Avoid | Why |
|---|---|
| journey | Corporate ceremony |
| vision | Unless paired with evidence |
| ecosystem | Overused beyond meaning |
| landscape | Consulting word |
| roadmap (as fluff) | Fine as a real document; dead as a gesture |
| value-add | Unforgivable |
| learnings | Lessons. Or findings. |
| stakeholders (as hedge) | Name them: clients, team, business |

---

## Phrase bans — if you catch yourself writing these, stop

- "At the intersection of X and Y"
- "Delivering value"
- "Trusted partner"
- "Proven track record"
- "Harness the power of"
- "Transformative journey"
- "Unlock the full potential of"
- "In today's fast-paced world"
- "In the age of AI" (unless specifically earned, e.g. the manifesto's own "Defining Excellence in the AI Age")
- "Cutting-edge solutions"
- "Future-proof"

## Punctuation & format

- **Title case in titles.** "First Principles" not "First principles" and not "FIRST PRINCIPLES."
- **Section labels UPPERCASE.** RX MENTALITY · RX BEHAVIOUR · RX OBJECTIVES.
- **Full stops at end of every sentence, including bullets.** (The manifesto drops them on some bullets; this skill keeps them for consistency on the site.)
- **No em dashes to break sentences.** Allowed mid-sentence for appositives: *"momentum over certainty — nothing else moves the ambiguity."*
- **Quote marks around reclaimed terms.** *"best practices"*, *"unproven"*, *"bubble"*.
- **"Ask:" always bold,** question always regular weight.
