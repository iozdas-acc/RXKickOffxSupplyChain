# WebContext-RXKickOff

New web project built with the WebContext workflow.

---

## Getting started

```bash
cd site
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

---

## Setup sequence

```
# 1. Drop brand assets into assets/raw/
# 2. Register them
/sync-assets

# 3. Fill context files
.impeccable.md                          ← brand context
.agents/product-marketing-context.md    ← product/marketing context

# 4. Plan site structure + confirm tech stack
/plan

# 5. Generate design system
/init

# 6. Design + build each page
/design [page]
/build [page]
```

---

## Project structure

```
WebContext-RXKickOff/
├── site/                    # Next.js app (stack TBD — confirmed in /plan)
│   ├── app/
│   │   ├── globals.css      # Design tokens + layout classes
│   │   ├── layout.tsx       # Root layout: fonts, Nav, Footer
│   │   └── page.tsx         # Home page stub
│   └── components/
│       ├── Nav.tsx
│       └── Footer.tsx
│
├── pages/                   # Design + build specs per page
│   └── _template/           # Copy this to scaffold a new page
│
├── design-system/
│   └── MASTER.md            # Generated by /init
│
├── assets/
│   └── raw/                 # Drop brand files here
│
├── memory/                  # Project memory (decisions, issues, preferences)
└── scripts/
    └── screenshot.js        # Playwright screenshot audit
```

---

## Notes

- `node_modules/` and `.next/` are gitignored — run `npm install` after cloning
- All design tokens live in `site/app/globals.css` — never use raw values in components
- All GSAP animations must respect `prefers-reduced-motion`
