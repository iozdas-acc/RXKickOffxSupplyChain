# The Hybrid Approach — Brief

## Purpose

Present the structural fix. The hybrid delivery model: RX AI-acceleration in the first half of the engagement, light-touch consulting agent in the second half to support client adoption. This page must make the model feel concrete and inevitable — the direct answer to the tension named in Chapter 3.

## Audience

Stakeholders who have just absorbed the learning. They're ready for the solution. They will scrutinise it: Is this just more weeks to protect commercial? Does the consulting agent actually help or is it a placeholder? The design must pre-empt these doubts with clarity of structure.

## Success criteria

1. Visitor understands the two-phase model clearly: RX-led first half, consulting agent-supported second half.
2. Visitor sees why this keeps CCI high while driving both value creation and client change in parallel.
3. Visitor believes the consulting agent is a genuine capability, not a commercial add-on.

## Sections / content blocks

1. **Chapter indicator** — "04 / 05"
2. **Section headline** — "The Hybrid Approach" (or a sharper label)
3. **Model visualisation** — a diagram or two-phase layout showing:
   - Phase 1: RX AI-acceleration (value creation at pace)
   - Phase 2: Consulting agent — light-touch, supports client team adoption
   - Outcome: CCI maintained, value creation + client change running in parallel
4. **Why it works** — brief explanation of each phase's role. Not a pitch — a structural rationale.
   - Phase 1: RX does what RX does best, at speed
   - Phase 2: the client isn't left to absorb alone — a consulting agent helps the team digest, implement, and build capability
5. **The commercial signal** — 1.5x faster delivery [TBD source]. CCI maintained [TBD baseline]. Value creation at pace AND client change at their own pace — not a trade-off.
6. **Transition** — "This isn't just the Sainsbury's model." → advance to Chapter 5.

## Copy tone

Precise and structural. This page should feel like an architect explaining a design decision — not a salesperson pitching a product. The consulting agent is a capability; describe it as such. No product names, no feature lists.
